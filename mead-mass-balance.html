Methodology & assumptions

  • Elevation and storage use data/mead_elevation_storage.json. The table values are used directly as Lake Mead live storage; no dead-pool adjustment is applied.
  • Inflow equals Powell release plus gains above Lake Mead. Defaults are 7.00 MAF and 655 kAF.
  • Outflow equals 9.00 MAF Lower Basin plus Mexico demand, minus shortage, plus 477 kAF fixed system losses, plus losses below Mead. The default below-Mead loss is 189 kAF.
  • This is a calendar-year planning calculation and does not represent an official operating forecast.
